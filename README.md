# 📊 AutoSolutions — Sales Performance

Dashboard desenvolvido em Power BI para análise do desempenho de vendas da AutoSolutions.

## 🎯 Objetivo

Analisar dados históricos de vendas e gerar indicadores para apoiar a análise de desempenho comercial e o planejamento estratégico.

## 📊 Principais KPIs

- **Vendas Brutas:** R$ 39,56 Bi
- **Custo dos Bens Vendidos:** R$ 25,38 Bi
- **Lucro:** R$ 14,18 Bi

## 💡 Principais Insights

- O segmento **Governo** representa 41,07% do lucro analisado.
- A **Fiat Toro** apresenta o maior volume de unidades vendidas, com aproximadamente 340 mil unidades.
- O **Canadá** apresenta o maior volume de unidades vendidas, com aproximadamente 247 mil unidades.
